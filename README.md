# Ricochet Rodeo

Абсурдний тир від першої особи: підкидаєш предмети, стріляєш, куля рикошетить у пляшки, мішені й вікна.
Зараз це прототип core loop з першим рівнем у графіці з концепту: Рівень 1 «Дикий Захід» — моделі Meshy з рефів FLUX 3 (конвеєр `tools/assets`), звук — справжній.

- **GDD:** https://claude.ai/artifact/Jasoede8snHywoHLQusnT3
- **Рушій:** Godot 4.7.x (Forward+, Jolt Physics), GDScript

## Запуск

1. Godot **4.7.x**. Project Manager → Import → `project.godot`.
2. Перше відкриття імпортує звуки (~200 файлів) — це хвилина.
3. F5. Головна сцена — `scenes/main.tscn`; рівень — `scenes/levels/01_wild_west.tscn` (збирає `tools/godot/build_level_01.gd`).

## Рівні з концептів

Конвеєр концепт → рефи FLUX 3 → Meshy → Blender → Godot: `tools/assets/README.md`. Маніфест рівня 1 — `art/levels/01-wild-west/assets.yaml`, порівняння з концептом — `art/levels/01-wild-west/compare.jpg`.

## Збірка під macOS

```sh
tools/build_macos.sh          # release-збірка і запуск
tools/build_macos.sh --debug  # debug-збірка
OPEN=0 tools/build_macos.sh   # лише зібрати
```

- Результат: `export/macos/Ricochet Rodeo.app` (в git не потрапляє).
- Пресет `macOS` у `export_presets.cfg`: ad-hoc підпис без сертифіката, без нотаризації — для запуску на своєму Mac.
- Потрібні шаблони експорту Godot (Editor → Manage Export Templates).
- На іншому Mac після AirDrop/завантаження: `xattr -dr com.apple.quarantine "Ricochet Rodeo.app"`.

## Що вже є

- Кидок 5 типів предметів з аркадною гравітацією: монета і гумова курка «пливуть», ковадло падає камінням. Вершина траєкторії завжди по центру екрана.
- Hitscan-постріл, трасер, рикошети від предметів і гонгів з «магнітом» до найближчої цілі в конусі.
- Гонг сам грошей не дає, але подовжує ланцюжок: гонг → пляшка = «РИКОШЕТ ×2».
- Скло (пляшки, вікна) пробивається — куля летить далі.
- Очки: ланцюжок рикошетів, bullseye, жонглювання, швидкий постріл, комбо до ×4 з вікном 1.5 с, штраф за картонного ковбоя.
- Slow-mo від 2-ї ланки ланцюжка, hit-stop на звичайному влучанні, тряска камери.
- Рука зі зброєю: інерція прицілювання, idle, віддача, перезарядка по набою (одна рука / дві руки), трюк у простої, спалах.
- Звук: 32 типи SFX (195 варіацій), ембієнт Дикого Заходу, музика гри й магазину, шини SFX / Music / Ambience.
- Рівень: 15 кидків → табло з зірками і статистикою.

## Структура

```
project.godot, scenes/          Godot-проєкт
scripts/
  main.gd                       ритм рівня, slow-mo, табло, музика, input map
  player.gd                     камера, стрільба, рикошет і магніт, перезарядка
  viewmodel.gd                  рука і зброя, усі анімації
  thrower.gd / throwable.gd     кидок і підкинутий предмет
  score_manager.gd              очки, комбо, статистика
  data/                         WeaponData / ThrowableData + пресети
  world/                        рівень, пляшки/вікна, мішень, гонг, цивільний
  fx/                           трасери, написи, уламки; sfx.gd + audio_manifest.gd
  ui/                           HUD і приціл
audio/sfx|amb|music/            готові звуки (генеруються скриптом, див. нижче)
source_assets/audio_raw/        сирі звуки з MusicGPT (Godot їх не імпортує)
art/concepts/                   концепт-арт — планка якості MVP
art/models/                     джерела моделей (.blend, Godot їх не імпортує)
assets/models/                  моделі для гри (.glb), експорт з art/models/
tools/audio/slice_sfx.py        нарізка і нормалізація звуків
docs/prompts.md                 промпти для концептів і звуків
```

Будь-який об'єкт стає ціллю, якщо має метод `on_bullet_hit(hit_pos, dir, normal, impulse) -> Dictionary`
і повертає `surface` (`object` / `metal` — рикошет, `glass` — пробиття, інше — куля зупиняється), `points` і `sound`.

## Звук

Сирі файли з MusicGPT лежать у `source_assets/audio_raw/` (по 4 варіації, серії звуків з паузами).
Скрипт ріже серії на окремі звуки, вирівнює гучність за категорією, додає фейди, робить безшовні петлі
для ембієнту й музики і перегенеровує `scripts/fx/audio_manifest.gd`:

```bash
# потрібні python3 + numpy і ffmpeg з libvorbis
python3 tools/audio/slice_sfx.py --src source_assets/audio_raw --project .
```

Як різати кожен звук і його цільова гучність — таблиця `SFX` на початку скрипта.
Тонке зведення в грі — `DEFAULT_DB` у `scripts/fx/sfx.gd`. Новий звук: поклади сирий файл, додай рядок у `SFX`, запусти скрипт, виклич `sfx.play("ключ")`.

## Наступні кроки

- Робоче середовище на Mac з Blender: моделі пропсів з концептів (Meshy/Tripo → Blender → glTF).
- Перенести рівень у `.tscn` зі справжніми моделями, 2D-бекдропом і пост-обробкою (див. GDD).
- Комікс-написи (RICOCHET!, CHAIN ×N) спрайтами замість `Label3D`, нумерація точок рикошету.
